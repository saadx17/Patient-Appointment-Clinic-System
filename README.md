# Patient Appointment Clinic System

This is a simple Java-based Patient Appointment Clinic System with OOP. It allows users to manage patient appointments in a clinic setting.

## Project Structure

- `Start.java`: Main entry point for the application.
- `Data/appointments.txt`: Stores appointment data.
- `Entity/Patient.java`: Defines the Patient entity.
- `Frame/ClinicFrame.java`: Contains the main GUI frame for the clinic system.

## Features

- Add, view, and manage patient appointments
- Simple file-based data storage
- Graphical User Interface (GUI)

## Requirements

- Java 8 or higher

## Usage

- Run the application and use the GUI to manage patient appointments.
- Appointment data is saved in `Data/appointments.txt`.
